# Xeno Modz Free Fire Proxy Panel

**Xeno Modz** is a Free Fire private server proxy tool designed for educational and development purposes. This tool simulates a mod panel where players can adjust in-game values like diamonds, rank, level, and unlock rare bundles.

> Built with **Node.js** (backend) and **HTML/CSS/JavaScript** (frontend) using **GitHub Codespaces**.

---

## Features

- Unlock all skins and bundles (e.g., Season 1–5).
- Claim 100,000 diamonds on first login.
- Adjust rank: Bronze → Grandmaster.
- Customize player level (10–100).
- Modify profile likes and views.
- View rewards in the Free Fire gift box with a message:  
  `"Thanks for joining Xeno Program"`.
